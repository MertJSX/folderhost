# Security Policy

## Supported Versions

Latest version is supported only. Use the latest version always. The older versions are used for backup. Version format:
```YYYY.MM.NN```

## Reporting a Vulnerability

The project is maintained by [Mert Sami](https://github.com/MertJSX). If you find a regular bug, please create an issue. If you find a security issue, please send an email to `contact@mertsami.com` or use GitHub's private vulnerability reporting feature.

Please include screenshots and a clear description of when the problem occurs. I'll do my best to respond quickly and fix the issue.
